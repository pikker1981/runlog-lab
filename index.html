Criteria

점수 기준표

Garmin 수면 점수와 바디 배터리는 사용자가 직접 입력한 원자료입니다. 앱점수는 총 수면, 깊은 수면, REM, 안정시 심박을 바탕으로 계산한 간이 평가입니다.

러닝 점수 기준

페이스, 평균 심박, 케이던스, 수직 비율, 지면 접촉 시간

  • 평균 페이스 5:00/km 이내 최상, 6:00/km 이내 양호, 7:00/km 이내 보통
  • 평균 심박 150bpm 이하 양호, 165bpm 초과부터 부담 증가로 감점
  • 케이던스 165~185spm 범위를 효율 구간으로 평가
  • 수직 비율 8% 이하 양호, 10% 초과는 상하 움직임 과다로 감점
  • 지면 접촉 250ms 이하 양호, 280ms 초과는 효율 저하로 감점

수면 점수 기준

Garmin 원점수 + 앱 자체 간이 평가

  • 수면 점수 Garmin에서 제공하는 수면 점수를 그대로 입력
  • 바디 배터리 Garmin 바디 배터리 수치를 그대로 입력
  • 총 수면 7~9시간 최상, 6시간 미만부터 명확한 감점
  • 깊은 수면 총 수면 대비 13~23%를 양호 구간으로 평가
  • REM 수면 총 수면 대비 20~25%를 양호 구간으로 평가
  • 주의 수면 단계는 기기 추정값이므로 절대 진단값이 아니라 경향값으로 사용
